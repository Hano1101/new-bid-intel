# 数据接入、附件质量与数据集管理

本文说明如何准备附件依赖、导入服务器目录、隔离数据集并核验解析告警。这里的历史统计各自标明日期和配置；它们不是同一次运行的合并结果，也不构成准确率。命题方提供原始材料而不提供逐条 Gold，现有 24 条 reviewed 数据已参与开发调试，只用于本地回归。

## 安装与能力检查

在 backend 虚拟环境安装依赖：

```powershell
python -m pip install -e ".[dev,ocr]"
```

旧 DOC 转换需要单独安装 LibreOffice，并按主机位置设置 `LIBREOFFICE_PATH`；DOCX、XLS/XLSX、PDF 表格、图片和归档解析由项目依赖提供。RapidOCR 是默认本地 OCR 引擎，首次运行需要取得本地模型文件；默认不依赖 Tesseract。启动后端后可查看 `GET /api/v1/parser-capabilities`，前端导入页也会提示缺少的解析能力。能力可用只表示依赖存在，不证明某份文件能正确解析或 OCR 结果准确。

转换或 OCR 失败、无效下载、加密/损坏成员和不支持格式都会保留来源并产生 warning。转换成功不等于字段抽取成功；扫描件、复杂跨页表格和格式不兼容的旧 Office 文件需要查看原件。解析警告分类与逐公告核对入口见公告详情和任务报告。

## 创建数据集并导入材料

在页面的“当前数据集”中创建新空数据集，并确认切换后显示 0 条公告。新导入写入该数据集；`default` 始终使用原数据库。不同请求通过 `X-Dataset-ID` 选择数据集，不带 header 时使用 `default`；未知 ID 返回 404，无效 ID 返回 422。模型配置是全局的，Gold 和评测运行目录另行管理，不随业务数据集切换。

大批量处理读取后端主机上的材料，不会上传浏览器本地文件。部署时在 `backend/.env` 设置 `INTAKE_ROOT` 并重启服务。目录选择器只允许浏览该根目录内的目录、不递归子目录；先预检，再确认 OCR、抽取模式和数据集后创建任务。预检后文件发生变化会拒绝创建并要求重新预检。只允许可信操作员和服务账号修改材料目录。

后台任务可从界面或 API 创建，也可在 backend 虚拟环境中使用 CLI：

```powershell
python -m app.jobs create D:/path/to/approved-data --name "批次名称" --mode rules --start
python -m app.jobs status <任务ID>
```

规则路线不调用模型。`hybrid` 或 `model` 会按端点和材料产生模型请求。任务进度、公告检查点、处理报告和解析缓存保存在本机数据目录；暂停或服务重启后可续跑，任务创建后材料变化须建立新任务。并发额度和恢复边界见[后台任务运行说明](bounded-jobs.md)。

## 附件、归档与来源边界

系统按内容识别 HTML、DOC/DOCX、XLS/XLSX、PDF、图片及支持的压缩格式。旧 DOC 通过 LibreOffice 转换；RapidOCR 识别图片和无文本 PDF 页。默认 PDF 页面上限和扫描页 OCR 上限均为 1000，可按部署需要配置。ZIP、RAR、7z 的后台展开有单公告大小、成员大小、深度和成员数量上限；接口能力和限制以 [`backend/.env.example`](../backend/.env.example) 及 [有界任务说明](bounded-jobs.md) 为准。

源文件按内容记录 SHA-256，原件不会被改写。验证码、维护页、JSON 错误等无效下载会被标为源材料不可用并排除在抽取外；不能让模型补造缺失内容。附件归属不明确、成员损坏、文件解码失败或 OCR 文本不可信时，应保留 warning 并人工对照原件。招标/需求模板等已识别参考文件会保留来源但不进入成交标的抽取。文件名编码可识别常见 UTF-8、GB18030 和 ZIP Unicode Path 形式；解码成功不保证附件归属正确。

## 新批次的核验步骤

1. 确认输入目录、格式依赖和 `INTAKE_ROOT` 权限；为重跑创建新的空数据集。
2. 先选取少量包含 HTML、DOC/XLS、PDF、扫描图和归档文件的材料，查看逐公告结果与 warning。
3. 核对公告与附件归属、候选来源片段、OCR 输出和失败清单；将不可读源文件与抽取漏报分开记录。
4. 再按材料数量和服务额度确定批次规模。若选择模型路线，记录端点 ID、配置、实际请求数和失败数，不将规则/OCR 吞吐写成模型吞吐。
5. 对字段准确性使用人工核验的 Gold 和 [`EVALUATION.md`](EVALUATION.md) 口径；说明数据集角色、Gold 版本和运行范围，不把候选数量当正确率。
