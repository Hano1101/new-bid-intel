# 原文证据链补充验收（2026-10-10）

## 结果

新导入路径已保存可复核的字段来源：公告元数据按显式标签保存正文行及文件名；表格标的按字段保存表头、单元格文本和行列定位。页面可单独打开字段片段，并展示关联的 SHA-256。

字段状态区分：

- `present`：抽取到值，且保存了对应字段的来源片段。
- `explicitly_not_published`：来源明确写有“未公示”“未公布”“未披露”等受控标记，并保留该字段片段。
- `blank_in_source`：对应表格单元格或标签值确实为空，并保留定位；不解释成“未公示”。
- `unverified`：有抽取值，但没有可核验的字段级来源，或值与空值证据冲突。
- `unknown`：没有值或历史来源状态未保存。

新导入会在内容识别、解压或文本转换前对原始上传文件/归档成员字节计算 SHA-256；若输入已有 hash/size，展开入口会比对字节并在不匹配时拒绝。压缩包中的归档容器本身不作为抽取文件记录，记录的是展开后的叶文件。应用不留存原件字节，哈希可用于日后与持有的原件比对，不代表系统仍能打开原件。

字段状态和字段证据随 hybrid 与跨文件候选融合中的字段值一起迁移。若模型提供了一个值但没有自己的字段级来源证据，值状态会成为 `unverified`，不会继续显示规则表格原来的“空单元格”状态。

## 历史数据边界

已有数据库不会被推断性回填：旧记录中的非空元数据/字段显示“待核验”，旧空值显示“状态未知”，没有原始字节哈希的来源显示不可用。只读审计记录显示，本地旧库覆盖 1,038 条公告、6,472 条标的；固定抽查 20 条均有记录级证据片段，但没有能关联到原始文件的旧哈希。检查到的官方 intake 目录有 18 个文件、没有 HTML 或 ZIP，当前未找到可用于重算历史文件 SHA-256 的原件。因此“历史原件校验”尚不能关闭；只有恢复相同的原始文件后才可逐份核对并补记 hash，不能用当前重新下载且身份不明的文件冒充历史原件。

这一只读审计不表示重新解析了 1,038 条公告，也不表示历史候选通过了字段级复核。当前新能力仅对之后通过新导入链路处理的文件生效；旧结果需持有原件后重新导入，才会生成新来源记录。原件文件不会因导入而留存在数据库。
