# 人工标注手册（标注员用）

> **这份是给标注员的。** 协调员的命令、脚本和分配流程见[协调员指南](ANNOTATION_GUIDE.md)。
>
> 你不需要装环境、跑命令或配置 API Key。你只需要一个浏览器、协调员发来的任务 ZIP 和页面链接。

## 你要做什么

按协调员指定的阶段，独立核对分给你的政府采购公告。试标阶段要和另一位标注员处理同一组公告，用于口径校准；校准后再做协调员分给你的正式样本。每个 ZIP 的条目数和你的任务范围以页面加载结果及协调员说明为准，本手册不规定固定样本数。

## 开工前，确认你拿到两样东西

| | 是什么 | 谁给你 |
|---|---|---|
| ① | 标注员专属 ZIP，例如协调员说明中的 pilot 或正式任务包 | 协调员 |
| ② | 标注页面链接，通常以 `/annotation.html` 结尾 | 协调员 |

缺任何一样就联系协调员。A、B 必须拿各自的包并独立填写，不要查看另一人的答案。若处于试标阶段，协调员会说明两份包包含相同公告；正式阶段则按各自的非重叠任务操作。

## 操作步骤

1. **解压 ZIP。** 把包解压到一个固定文件夹。保留其中的 `*.bundle.json` 和 `sources/` 原件目录；只有 bundle 文件无法查看配套原件。
2. **打开网页。** 在 Chrome 或 Edge 打开协调员发来的链接。共享页面要用协调员提供的网络地址，不要把 `localhost` 发给另一台电脑。
3. **载入任务。** 点“载入我的标注任务”，选择 ZIP 中的 `*.bundle.json`。确认页面顶部显示了正确任务名和公告数；如果任务数与协调员通知不符，先停下并联系协调员。
4. **逐条填写。** 对照左侧公告和 `sources/` 中的原始附件，在表单中核对标的七字段、采购单位、中标方和投标方。解析/OCR 文本只是查找线索；扫描件和复杂表格要打开原件。每条完成后勾选“本公告已对照原文”。
5. **导出结果。** 全部任务核验后点页面的“导出已核验 Gold”按钮，把自动下载的 reviewed JSON 原样交给协调员，不要改名。未完成时导出的文件会带 `.partial`，只能作为进度，不可用于最终合并。

## 填写规则

1. **只记录原文明确支持的内容。** 未披露才留空/null；不能用常识或推理补值。
2. **机器候选不是答案。** 页面已有的内容也要逐项和原文核对，即使看起来正确。
3. **名称照抄原文。** 不自行合并简称、分公司或相似主体。

| 情况 | 填写方式 |
|---|---|
| 原文写品牌是“华为” | 填 `华为` |
| 原文写“见附件”，附件中也找不到 | 留空；若附件缺失或不可读，保持未核验并联系协调员 |
| 原文金额为“￥1472.6085 万元” | 填 `14726085` 元 |
| 数量为“2台” | 数量填 `2`，不带单位 |
| 甲公司中标 | 中标方列表和投标方列表都填甲公司 |
| 写明有多家公司投标，但未写谁落标 | 投标结果选“结果未披露”，不要猜成未中标 |
| 原文明确写某公司未中标 | 选“明确未中标” |
| “甲乙联合体”中标 | 记录“甲乙联合体”一个主体，不拆分成员 |
| 原文没有分包 | 包号填 `default` |

标的字段包括产品/服务名称、品目、品牌、规格型号、数量、单价和总价。金额统一人民币元；不要用单价乘数量推导总价，也不要把项目中标总额复制到每个标的。按公告原文记录包/标段，不要为了与预测对齐而改包号。

## 不能勾选核验的情况

页面会阻止以下内容通过核验，并提示需要检查的字段：标的行七字段全空、包号为空或重复、主体名称为空、数字格式非法。看到提示后按页面说明修正。修改过任何字段后，之前的核验会自动撤销；改完要重新对照原文再勾选。

附件打不开、损坏、像验证码/错误页面、与公告的对应关系不清，或你无法确定包号时，不要猜，也不要勾选核验。记下公告 ID 和包号，联系协调员。

## 中途暂停和交接

页面会按任务 ID 自动保存在当前浏览器的 IndexedDB 中，但自动保存不能跨设备或浏览器配置。离开前点“下载进度备份”；恢复时回到页面，仍点“载入我的标注任务”并选择该备份。

## 遇到问题

| 情况 | 怎么办 |
|---|---|
| 页面打不开 | 确认使用协调员发来的共享链接，并检查是否连到指定网络 |
| ZIP 中没有 `sources/` 或 bundle | 联系协调员重发，不要只靠解析文本继续标注 |
| 附件打不开、乱码或不可读 | 记录公告 ID 和包号，跳过该条并告诉协调员 |
| 不确定某字段该不该填 | 先不猜，记下疑问并询问协调员 |
| 原文与预测差异很大 | 以原文为准，按实际内容填写 |
| 两条公告似乎是同一项目 | 分别照公告填写，并请协调员确认关联处理 |

本地 Gold 和评测结果不是官方成绩，不要对外当作准确率宣称。完整字段口径见 [EVALUATION.md](EVALUATION.md)；Gold 文件结构见 [evaluation_gold.schema.json](../examples/evaluation_gold.schema.json)。
