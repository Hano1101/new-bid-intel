# 系统演示视频脚本（目标不超过 5 分钟）

## 录制前

- 使用离线虚构数据集，避免录入官方原始材料、API Key、密码或内网地址。
- 录制 1080p 横屏；关闭通知和无关窗口；准备一条关系线索、一条证据详情；版本比较需预先导入同公告两版材料，离线种子不会自动创建版本对照。
- 可用本机浏览器展示完整流程；采用局域网方式时，配置说明见 [`docs/LAN_ACCEPTANCE.md`](../docs/LAN_ACCEPTANCE.md)。

## 时间轴

| 时间 | 画面与旁白 |
|---|---|
| 0:00–0:20 | 打开登录页，说明系统面向采购公告抽取和关系核查。 |
| 0:20–1:00 | 选择离线数据集，展示公告导入/批量任务状态和 warning 隔离。 |
| 1:00–1:45 | 打开公告详情，展示七字段、采购单位、投标/中标记录、来源片段和文件哈希。 |
| 1:45–2:35 | 在五类分析中选择采购单位/供应商，展示项目、包、金额口径和实际分析后端。 |
| 2:35–3:15 | 打开关系图搜索和关系线索卡，展开一条线索并跳转证据详情。 |
| 3:15–4:00 | 打开人工复核队列，接受或修正一条候选，展示理由和历史事件。 |
| 4:00–4:35 | 打开公告版本历史，比较两版附件/包/金额变化，展示待人工确认提示。 |
| 4:35–5:00 | 展示模型不可用时 rules 离线路径和清晰的限制说明，结束。 |

## 录制后检查

确认视频为横屏 1080p、时长符合要求、文字可读、没有敏感信息；使用播放器完整播放一遍，记录最终文件的分辨率、时长和 SHA-256。
