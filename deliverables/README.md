## 赛题交付规格

| 材料 | 规格与内容 |
|---|---|
| 系统设计 | Word 与 PDF；核心亮点预览、业务需求、技术选型、数据模型、功能设计、测试效果 |
| 过程性报告 | 技术路线对比与数据质量分析；同时提供 Word 与 PDF |
| PPT | 完整演示内容，设置核心内容预览页；避免特殊识别信息 |
| 汇报视频 | 1080p 横屏 MP4，时长不超过 10 分钟 |
| 系统演示视频 | 1080p 横屏 MP4，时长不超过 5 分钟；展示任务一、二在平台中的操作流程 |
| 源码压缩包 | 工程、版本环境、关键注释、任务一结果表、任务二数据模型和操作说明 |

初赛按赛题内容框架自行组织文档，无需等待统一模板。最终提交前按学校的文件命名和提交入口要求检查。

## 数字与范围

材料统计为 1,038 条公告、13,136 个附件叶文件；2026-10-14 的下载字段补录共检查 14,174 个来源文件。最新后端回归为 703 passed、6 skipped，任务三实际页面登录、上传、下载和数据集隔离验证通过。24 条 reviewed 数据已经参与开发，只作为本地回归。技术路线表的历史分数属于 official_qa 本地解释口径，与 Gold v2 的 local_proxy 重评分分开呈现；不包装成官方成绩。

公开仓库不包含密钥、账号、数据库、原始模型响应或未经审查的材料。赛题要求的任务一结果表与任务二数据模型进入受控交付包，具体结构见源码与数据索引。
