# 源码与配套数据交付索引

该索引用于制作最终源码压缩包，不包含密钥、数据库、官方原始材料或模型响应。

## 应提交

- `backend/`：FastAPI 服务、解析/抽取/查询/任务/评测代码和测试。
- `frontend/`：Vue 分析台、人工复核、关系图、版本历史和标注工作台。
- `scripts/`：启动、停止、账号配置、局域网诊断和资源验证脚本。
- `examples/`：虚构离线演示输入和公开 schema。
- `docs/`：架构、运行、数据质量、查询口径、评测边界、创新点和验收清单。
- `deliverables/`：系统设计、技术路线、数据质量报告源稿、PPT 大纲、视频脚本和本索引。
- `backend/neo4j_runtime/`：可选 Neo4j Compose 配置和说明。

## 不能提交

- `backend/.env`、`backend/.data/`、SQLite 数据库、评审账号和任何 API Key。
- 官方 1038 条原始 HTML、ZIP/RAR/7z、附件和原始模型请求响应。
- `frontend/node_modules/`、Python 虚拟环境、构建缓存、`.coverage` 和本机临时文件。
- 未经公开审查的完整附件审计台账或包含本机绝对路径的内部诊断文件。

## 数据说明

官方数据的任务一提取结果和任务二关系模型属于本地运行产物。按赛题源码交付要求，受控提交包需包含任务一提取结果表和任务二关系数据模型，附字段说明、数据来源、代码提交号、运行时间和 warning 统计。公开 Git 仓库仅保留可公开样例和聚合统计；本地 Gold 不当作提取结果或官方答案。
