# 招采公告与附件数据质量分析报告

初赛过程性文档 · 2026-10-11 · 版本 1.0

## 1 数据范围与质量结论

系统已对 1,038 条采购公告及其附件完成本地处理与分类盘点，能够对复杂格式、失败附件、参考材料和无效下载响应保留来源并隔离处理。数据治理重点是让可用内容继续进入抽取流程，让异常内容可解释、可追溯，不让单个坏附件中断整批任务。

本报告数量对应 2026-09-30 的全量历史快照，不表示当前代码重新处理后的结果。解析覆盖、字段抽取正确性和查询实现一致性是不同指标；解析产生文本不能直接视作七字段正确。

## 3 质量控制方法

| 环节 | 控制措施 | 输出给用户的信息 |
|---|---|---|
| 内容识别 | 比对实际内容与扩展名；识别旧式 Office、WPS 和专有格式 | 实际格式、来源和格式差异告警 |
| 归档展开 | 限制深度、成员数和大小；损坏成员独立隔离 | 成员读取失败、超限和路径来源 |
| 文档解析 | PDF 主解析器与回退、Office 转换、OCR | 成功、部分成功、程序失败和 OCR 状态 |
| 材料用途 | 区分本次采购、历史案例、合同范本和参考材料 | 用途判断、过滤理由和保留来源 |
| 候选抽取 | schema、数值、包号证据和跨文件对齐保护 | 字段、连续证据、冲突和 default 警告 |
| 人工复核 | 按质量信号排序，保留决定及前后值 | 接受、修正、驳回和事件历史 |

WPS 进入旧 Word 转换路径；GBQ7 和 DWG 明确保留为不支持格式。无效响应、不可恢复源文件和不支持内容不由模型补造。PDF 定向恢复或后续解析修复属于单独实验，不改写这份冻结快照。

## 4 字段与关系质量

七字段保存源材料中可支持的信息。项目总金额、中标主体金额和单个标的总价分别建模；金额保留十进制精度和单位。当前查询只汇总已披露的标的总价，不通过数量和单价替代原文缺失值。采购人天服务、税金等因素可能造成标的合计与项目总额不一致，不能据此自动判错。

品牌与中标供应商分别处理，不以法律实体名称自动补品牌。参与主体保存 winner、nonwinner、unknown，结果未披露不等于未中标。名称型包号要求明确标签和值；缺可靠映射时使用 default，并提示包级统计可能合并。

## 5 来源证据与复核流程

新导入保存可获得的采购单位元数据证据、标的列级证据、明确未公示或空单元格状态以及输入 SHA-256。公告详情显示来源文件、定位、片段、警告和哈希。同名文件对应多个哈希时提示歧义，不把错误哈希当作证据。

历史数据中未保存的证据不能追溯生成：非空旧值显示待核验，旧空值保留未知状态。哈希只用于核对文件内容，不等于保存原件；应用不提供未保留原始字节的旧附件下载。

人工复核队列根据字段缺失、证据不足、OCR 或附件告警、default 包号和金额冲突排序。接受、修正和驳回记录操作者、时间、理由及前后值，候选代次防止重新导入后串接旧历史。复核覆盖与原机器候选分开保存，不自动回写 Gold 或改变统计结果。

## 6 本地标注与质量复查

团队 reviewed 数据用于逐条对照原文和开发回归，预测不作为真值。当前 24 条样本已经参与过诊断，后续指标保持本地回归口径。来源修订生成 Gold v2 并保留旧版及修改台账；不覆盖历史预测和报告，不把两种 Gold 或两种 profile 的数字直接比较。

质量复查覆盖正文表格、附件表格、扫描件、旧式 Office、多包、多中标人、零候选及异常响应。复查项包括公告身份、包号、七字段、采购单位、参与角色、来源定位、哈希、告警和处理决定。独立保留异常记录，避免只抽查成功案例。

## 7 交付与数据管理

公开仓库提供解析代码、测试、schema、虚构样例和聚合质量统计。任务一结果表、任务二关系模型和运行清单按比赛要求进入受控交付包；API Key、评审密码、原始模型响应和本机路径不随公开仓库发布。

统计的日期、输入范围和失败分类均可回溯至快照。1,038 条处理完成说明管线具备实际材料处理能力；字段准确性以明确 Gold、指标 profile 和匹配边界下的本地结果表述。该区分使评委可以分别核查系统能力、数据质量和算法效果。
